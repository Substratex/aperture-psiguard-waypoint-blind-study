## Declaration

This repository is designated by **SubstrateX® / Evidence Commons™** as the official Evidence Commons** artifact created from an independently originated external runtime** and preserved as a portable Runtime Evidence record.

The underlying Waypoint T1–T275 trajectory did not originate inside SubstrateX Aperture™. It was supplied as an external long-horizon computational record and then passed through Aperture's controlled evidence pipeline:

> **External Source → Qualification → Canonical Runtime → Evidence Computation → Runtime Evidence Passport → Evidence Artifact → Evidence Commons Preservation**

The resulting evidence family was bound to a certified runtime identity, preserved with explicit provenance and claim boundaries, hashed for integrity verification, and exported outside the Aperture interface so that the record can be independently inspected without requiring access to the originating application session.

This designation marks the transition of Evidence Commons from a preservation concept into an operational evidence practice.

## Why this artifact is significant

Evidence Commons is intended to address a basic problem in computational accountability:

> **Evidence should not disappear when the interface closes, the vendor changes, the model is updated, or the original runtime is no longer available.**

A dashboard can display a conclusion.  
A Runtime Evidence Artifact preserves the evidentiary basis that authorized that conclusion.

This repository therefore exists as more than a project archive. It is a preserved, externally inspectable evidence object designed to support:

- scientific review and reproducibility;
- independent technical scrutiny;
- audit and forensic reconstruction;
- institutional and organizational accountability;
- civic and public-interest accountability where computational systems affect people, institutions, or public infrastructure;
- long-term preservation of machine-readable evidence;
- challenge, disagreement, and re-analysis without rewriting the original record;
- comparison across independently developed analytical systems.

The governing principle is:

> **The evidence must remain inspectable after the system that produced the interpretation is no longer present.**

## Cryptographic integrity and portability

The purpose of cryptographic sealing in this artifact is not to certify that the original source is objectively true.

It is to make the preserved evidence family tamper-evident and to bind exported objects to a known evidence identity.

The preserved hash relationships allow an independent reviewer to determine whether:

- the source used for analysis matches the frozen source record;
- the Runtime Evidence Artifact belongs to the certified run;
- the Passport identity matches the certified canonical runtime;
- exported files have changed after preservation;
- a later analysis is using the same evidence object or a modified derivative.

This distinction is fundamental:

> **Integrity proves continuity of the preserved record. It does not prove the truth of the world described by that record.**

## Accountability function

This artifact demonstrates the intended accountability role of Evidence Commons.

A computational system should not be able to rely on a transient interface, proprietary dashboard, generated summary, or unverifiable internal state as the sole basis for an important claim.

Instead, a reviewer should be able to ask:

- What source was supplied?
- What transformations were applied?
- What evidence identity governed the run?
- Which measurements were supported?
- Which claims were permitted?
- Which claims were withheld?
- What remained missing or unresolved?
- Can the result be reproduced?
- Can the evidence be challenged independently?
- Has the preserved record changed since issuance?

The artifact is therefore designed to support accountability through **inspectability, provenance, bounded claims, integrity, portability, and preservation**.

## Civic and public-interest relevance

Evidence Commons is not limited to laboratory research.

As autonomous and semi-autonomous computational systems increasingly participate in organizational, commercial, institutional, and public workflows, consequential decisions may depend on records that are difficult to reconstruct after the fact.

Portable Runtime Evidence provides a possible evidentiary layer for contexts in which affected parties, auditors, researchers, regulators, institutions, or the public may need to examine what a computational system did and what the available evidence actually supported.

This artifact does **not** establish a legal evidentiary standard, regulatory certification regime, or universal accountability framework.

It demonstrates a technical architecture for preserving computational evidence in a form that can remain inspectable outside the application that produced it.

## Claim boundaries

This Evidence Commons designation does **not** assert that:

- the original source is objectively true or authentic merely because it is preserved;
- Aperture's measurements are universally valid;
- PsiGuard and Aperture have already demonstrated agreement;
- temporary prospective `t*` emissions constitute stable Basin Exit confirmations;
- formal lead time exists without an independently supplied `tf`;
- the findings generalize beyond this trajectory;
- Runtime Evidence certifies causation, intent, consciousness, hidden model state, or ground truth.

Evidence Commons preserves what was supplied, what was computed, what was authorized, what remained unavailable, and how the resulting record can be independently examined.
